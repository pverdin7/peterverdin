# v3.3 — restrained personal graphics

Reference: the user's Slow by Slow presentation, especially its small hand-drawn loops and uncluttered cards, without copying the deck's unique illustration or artwork.

- Removed the loud multi-layer bursts, jagged ribbons, repeated arches and compound graphics introduced in v3.2.
- Two small motifs now define the visual accents: **one organic blob** or **one gestural squiggle**. No burst/star motifs.
- Each career role now contains **one** accent across its 3–4 metric cards (11 accents, not 35); the other metric tiles are deliberately clean.
- Project gallery uses the same restrained marks, placed at the right edge behind the typography.
- The three opening-story frame accents use one path each. The hidden arch SVG under the hero portrait was removed.
- Prior v3.2 type-size improvements retained.
- All existing functionality—worker, password gate, R2 bindings, document preview viewer and case-study IDs—unchanged.

## Deploy
Use the small changed-files ZIP in GitHub, then commit. No need to change `wrangler.toml`, Cloudflare secrets, D1 or R2.
Check `/my-work/#by-role` on desktop and mobile. Clear browser cache if needed; styles and site.js have a `20261029-editorial33` cache tag.
